# Gemma 4 Developer Agent

Travail sur la compétition Kaggle *Google – The Gemma 4 Developer Agent* et son Paper Track.

- `research/paper/` : article *Summarized Before It Edits* (compaction de contexte et réussite d'un agent de code local), scripts de reproduction (`release/`), dataset et notebook Kaggle publiés.
  - Notebook : https://www.kaggle.com/code/stanleyhonkpehedji/gemma4-compaction-repro
  - Dataset : https://www.kaggle.com/datasets/stanleyhonkpehedji/gemma4-agent-compaction-traces
- `submissions/` : variantes d'agents (prompts, configurations ADK).
- `kaggle/` : générateur de kernels d'évaluation et de soumission.
- `tools/` : évaluation locale, comparaison de passages, veille publique, automatisation.
- `notes/JOURNAL.md` : journal des décisions et des résultats.

Non inclus : environnements Python, données et traces brutes de la compétition, notebooks publics d'autres auteurs.
